# CodeCafe Atlas v1.0.24.38

## Mejora de interfaz

- El Insertador inteligente de contadores ahora usa dos paneles horizontales.
- El panel izquierdo reúne la hoja maestra, pestaña, mapeo, origen, fuentes y autorizaciones.
- El panel derecho muestra el resumen, la tabla completa, el detalle y la generación de la copia.
- El divisor se puede arrastrar y Atlas recuerda su posición para sesiones posteriores.
- Las opciones extensas se presentan verticalmente para aprovechar mejor el ancho disponible.

## Alcance protegido

Esta actualización no cambia el análisis de contadores, la coincidencia exacta de series, las advertencias de series parecidas, la creación controlada de filas, la regla de `En Operación`, la protección de fórmulas ni la escritura de discrepancias.

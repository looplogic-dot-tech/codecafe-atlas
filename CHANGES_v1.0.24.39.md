# CodeCafe Atlas v1.0.24.39

## Registro de contadores

- PDF.js 3.11.174 y su *worker* ahora se distribuyen dentro del módulo.
- La apertura y visualización de PDFs ya no depende de descargar el lector desde Internet.
- Los rechazos muestran el nombre del archivo y la causa informada por el lector.
- Se diferencian documentos protegidos, dañados o que dejaron de estar disponibles.
- La caché conserva como máximo dos PDFs abiertos y libera automáticamente los anteriores, incluso en lotes de cientos de archivos.

## Compatibilidad

- Se conserva el procesamiento de imágenes.
- No cambia la extracción OCR, la captura editable, la base de datos ni los reportes Excel/CSV.
- Se incluye la licencia Apache 2.0 correspondiente a PDF.js.
